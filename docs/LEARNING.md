# 学中文功能说明

人生广场 · 学中文是「人生广场 · Life Plaza」的中文学习版：同样走进梅里爱、梵高、李时珍、孙悟空的一段人生，但每位人物说的中文都按学习者的 HSK 等级控制难度，并在画面上叠加一层学习界面（拼音字幕、词卡、词汇链、纠错）。

## 体验入口

| 用途 | 地址（本地运行后） |
|---|---|
| 首页，先选 HSK 等级 | `http://127.0.0.1:8080/life-learn/` |
| 老师发给学生的链接，直接定好等级（1–9） | `/life-learn/?level=2` |
| 直接进梵高的屋子（主演示） | `/life-learn/?go=vangogh&level=3` |
| 宣传片 | `/life-learn/media/learn-film.html` |

已经选过等级的浏览器，点屏幕顶部的「HSK n · 学中文」可以重新选。

## 功能

1. **分级入口**：第一次进来先选 HSK 1、2、3、4、5、6、7–9 级，或「我说中文」进原版体验。老师可以发带 `?level=` 的链接，学生打开就是那一级。
2. **界面语言**：HSK 1–3 级用英文界面，人物说适合等级的中文；4 级以上全中文。
3. **难度控制（HSK 3.0）**：使用 Gushi 整理的 HSK 3.0 大纲（11,000 个词、3,088 个字、428 个语法点）。人物或引路人每次说话，都会带上这一级的规则：1–3 级把这一级允许的词和语法点直接交给模型，并限制句长；4–6 级给词汇范围；所有等级都不用成语、古文和古白话。实测（HSK 3 级学习者，梵高的台词）：超纲词比例从原版的 50% 降到 16%，剩下的多是屋里看得见的东西（窗户、向日葵），正好是“略高于现有水平”的新词。李时珍原来那句「老夫三回乡试没考中，推的时候比你更使力气」变成「我考了三回，没考中。后来跟我父亲学医」。
4. **学习字幕**：人物或引路人一说话，屏幕上方出现一条字幕：每个词上面标拼音，超出等级的新词用橙色虚线标出，人名地名用青色，下面是英文翻译；可以重听、开关拼音和英文、收起。
5. **词卡和词汇链**：点字幕里任何一个词，弹出词卡：拼音、HSK 等级（超出你的等级会标 new）、英文、例句（带拼音和英文）、发音；「词汇链」给出下一步可以学的词（比如「黄色」→ 白色、黑色、红色、绿色、颜色）；再往下是易混词、常见搭配、常见偏误、语料例句。
6. **引路人按学习兴趣推荐**：引路人会问你为什么学中文、喜欢什么，按兴趣推荐第一段人生：画画、颜色、艺术或还不知道选谁的去梵高那儿，电影、拍照、魔术去梅里爱那儿，中医、喝茶、健康去李时珍那儿，小朋友和喜欢故事、冒险的去孙悟空那儿。
7. **循环提问（TCI）**：一次只教一个新词，同一轮里重复它，先问「是不是」，再问「哪一个」，最后问开放的问题。实测：学习者说「我喜欢黄色」，梵高答「我也喜欢黄色。你看，床和椅子都是黄色的。你喜欢黄色还是红色？」
8. **重述而不纠错、听得懂中英混说（超语）**：学习者说错了，人物不指出，只在回答里把对的说法自然说一遍；学习者夹着英文说，人物听得懂，并顺带说出中文。
9. **互动语言学式的语法解释**：问「把门打开」和「门打开了」有什么不一样，梵高答「把门打开，是我请人去开门。门打开了，是门已经开了。」——不讲术语，只给一个例子。
10. **纠错，自己再写一遍**：学习者打字说的中文有错，左下角弹出卡片：最多两条建议，带拼音和一句解释，要他把整句再写一遍，写对了才算完。例如「这个东西太好吃」→「太好吃了」。
11. **梵高「把窗户打开」**：推窗之前，梵高先说「请你把窗户打开。」，提示写「把窗户打开 · Hold to open」；学习者推开窗后，梵高第一句是「你把窗户打开了。」。
12. **梵高的固定台词**：英文界面下，梵高房间里原来写死的英文台词改成了简单中文（30 处），物品标签改成中英双语（「向日葵 · Sunflowers」），推荐提问改成学习者能照着问的中文（「你喜欢什么颜色？」）。

## 数据来源：哪些是真实的，哪些是模型生成的

- **来自 HSK 3.0 数据**：拼音、等级、例句、难度控制规则。
- **模型实时生成**：人物说的话、字幕翻译、纠错。
- **模型现写的近似数据**：词卡里「易混词、常见搭配、常见偏误、语料」四栏，由大模型按这个词现场写出，不是知识图谱或语料库的真实数据，接口返回的 JSON 里带 `source: "mock"`。
  - 关掉这四栏：在 `.env` 里加 `LEARN_KG=off`。
  - 接入真实的知识图谱 / 语料接口：只需要改 `server/learn/api.mjs` 里的 `graphOf()` 一个函数。
- **词汇链**：用 HSK 词表近似——和这个词共用一个字、等级离学习者最近的词。

## 学习接口（`/life-learn/api/learn/…`）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/learn/meta` | 数据署名、来源、词表规模 |
| POST | `/learn/annotate` | 一句中文 → 分词、拼音、等级、是否超纲 |
| POST | `/learn/translate` | 一句中文 → 英文翻译 |
| GET | `/learn/word?w=…&level=…` | 词卡：拼音、等级、英文、例句、词汇链 |
| GET | `/learn/graph?w=…` | 易混词、搭配、偏误、语料（见上节） |
| POST | `/learn/feedback` | 学习者写的一句中文 → 最多两条修改建议 |

其余接口（拜访计划、对话、语音合成、实时语音识别、生成礼物）沿用人生广场原版，见 `server/index.mjs` 文件头的完整列表。所有请求带 `X-Learn-Level`（1–9）和 `X-Learn-UI`（`en` / `zh`）头时进入学习模式。

## 宣传片

- `www/life-learn/media/life-plaza-learn-film.mp4`（2 分 13 秒，1080p，中文旁白，中英字幕烧在画面里），分享页 `media/learn-film.html`，字幕文件 `media/life-plaza-learn-film.srt`。
- 顺序：片头 → 为什么 → 选水平 → 引路人 → 梵高（推窗指令、学习字幕、词卡和词汇链、循环提问、语法解释、纠错重写）→ 梅里爱 → 李时珍 → 孙悟空 → 用户故事 → 标语 → 片尾。逐镜头的旁白、字幕和画面见 [`video-storyboard.md`](video-storyboard.md)。
- 画面构成：背景是原版人生广场宣传片里真机录的游戏画面；叠加的学习字幕、词卡、纠错卡是学中文版的真实界面截图，台词是测试时人物真实说出来的话；旁白是引路人的声音（语音合成）。
- 重新生成：`node video/shots.mjs`（界面截图，需要 Playwright 浏览器）→ `python3 video/make.py`（需要 ffmpeg 和正在运行的后端）。

## 已知限制

1. **前端不是原始源码**：`www/life-learn/` 是人生广场线上构建产物用 prettier 重新排版后的代码（约 4.4 万行），可读、可改，加载行为与原版一致；学习层是独立的 `learn/learn.js`、`learn/learn.css`。
2. **其他房间的固定台词**：英文界面下，只有梵高房间写死的台词改成了中文；李时珍、孙悟空、梅里爱房间写死的台词仍是英文（他们现场说的话是中文）。
3. **场景词偏难**：孙悟空、李时珍的台词里仍有一些场景专用词（师父、帖子、号脉），可以点词卡学。
4. **需要显卡**：3D 场景（splat 世界）需要有 WebGL 的设备，建议用带显卡的电脑或较新的手机。
